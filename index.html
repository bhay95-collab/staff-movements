Leave & Cover

Who is away, week by week, and whether their FTE is covered. Red = nobody covering. Amber = part covered. Green = covered.
Built live from Movements, using the same rules as FTE Gaps: leave, secondments out, vacancies, flexible work arrangements and part-returns from parental leave. Cover = backfill, acting or secondment-in movements that name the absent person as owner, counted only for the weeks they overlap. Heavier line = pay-cycle start.

Teams & roles

Build your own service structure: teams, and the roles inside each team.
▾
A team is any grouping you use (a ward, service line, rotation area). A role is a funded position inside a team. Each role has a classification (pay grade) and funded FTE. Funded FTE on roles adds up to the baseline for each classification, so the budget stays in step. Staff lines are then assigned to a team and role in the Staff Register.

Classification budget

Add, rename or remove classifications and set the funded FTE for this service.
▾
Baseline FTE = your funded establishment for that classification. Where roles use a classification, its baseline is added up from those roles automatically; otherwise you can type it here. Ceiling = the most you are permitted to run. Additional approved = extra FTE signed off outside the baseline (e.g. new grant funding) — it is added to the ceiling, not the baseline.

Shared data & backup

Keep one shared copy of the data in a OneDrive folder, with automatic daily backups.
▾
Set up once on each PC.
1. In File Explorer, make a folder inside OneDrive (for example StaffMovements). Share it with the other person with Can edit permission, and have them sync it to their PC.
2. Put this tracker file (index.html) in that folder too, and open it from there in Microsoft Edge or Google Chrome.
3. Click Link shared folder above, pick that same folder, and choose Edit files when the browser asks.
4. Each new browser session you may see Reconnect — one click, no data lost.
Every save writes to StaffMovementTracker-data.json. A start-of-day snapshot goes in the backups folder (last 45 days kept), and OneDrive also keeps its own version history of the file.
